## Context

GestPlay is a serious game developed in collaboration with LudoLab, designed for children with disabilities. It was
built with the Godot game engine, using MediaPipe for gesture recognition and TensorFlow for training and predicting
gesture models.

## Solution

A companion web app was also built in React to visualize usage statistics. The project prioritized accessibility
standards, tailored to the specific needs of its target audience.
