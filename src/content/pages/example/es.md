## Contexto

GestPlay es un videojuego serio desarrollado en colaboración con LudoLab, orientado a niños con discapacidades. Se
utilizó el motor Godot para el juego, MediaPipe para el reconocimiento de gestos y TensorFlow para entrenar y predecir
los modelos de gestos.

## Solución

Se desarrolló además una web complementaria en React para visualizar estadísticas de uso. El proyecto priorizó el
cumplimiento de estándares de accesibilidad, adaptándose a las necesidades específicas del público objetivo.
